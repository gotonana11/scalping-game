# scalping-game

スキャルピング練習用のシミュレーションゲーム。`index.html` をブラウザーで開いて利用できます。

板は数量0の価格も含めて1円刻みで表示します。売数量・買数量の欄をクリックすると、その方向と現在のロットで指値注文を出します。価格欄は選択中の方向で発注します。同方向・同価格の再クリック、注文一覧の取消、全取消で待機注文を取り消せます。板数量は推定値です。保有ポジションと逆方向の注文は返済指値となり、発注時のロットと保有数の小さい方を注文数量にします。約定時も残った保有数が上限で、反転しません。元のポジションがなくなった返済指値は失効します。現在値が指値条件を満たすと、その現在値で約定します。資金の予約や部分約定は行わず、約定時に資金不足なら失効します。Resetは注文履歴を消去します。

## 検証

Node.js、Playwright、Chromiumがある環境でリポジトリのルートから実行します。

```sh
node tests/orderbook.cjs
```

指値の待機・約定・取消、数量固定、資金不足、部分決済、反転、平均取得価格と残高、Reset、モバイル表示を確認します。
